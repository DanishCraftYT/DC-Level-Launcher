# DC-Level-Launcher
a improved version of the original Level Launcher made by Superboo07.<br>

## Features:
* play mods.
* custom maps (WIP).
* custom player models (WIP).
* backwards compatible with the original Level Editor made by Superboo07.
* cross-platform (WIP).
* settings editor.
  - supports type detection.

## next minor release (V0.2.0):
* support for custom maps.
* bug fixes.
